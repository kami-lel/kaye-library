# Kaye Library: Codex Usage Documentation

English | [简体中文](codex-usage-doc.zh-CN.md)

Install `kaye-library` in the Codex app by adding its marketplace.

> [!WARNING]
> Codex support is not actively maintained or well tested: some steps may not work as described.

## for Codex App

### ⓐ Add the Marketplace by URL

1. Open *Plugins*.
2. Click *Add marketplace*.
3. Type this in the *Source* field, then save:

   ```text
   https://github.com/kami-lel/kaye-library-marketplace.git
   ```

4. Restart Codex if it asks you to.
5. Back in *Plugins*, choose `kaye-library-marketplace` as the source.
6. Find *Kaye Library*, then click its *+* button to install it.
